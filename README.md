# KeyCraft Pro - Android System Keyboard (IME)

This is the complete Android Studio project for **KeyCraft Pro Keyboard**, an Android Input Method Editor (IME) that can be set as your **Default System Keyboard** on Android.

## Features as Android Default Keyboard
- Works in WhatsApp, Telegram, Chrome, Notes, Gmail, SMS, Instagram, and any app on Android!
- Dedicated **CTRL** button with system clipboard shortcuts (Ctrl+A, Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+Z, Ctrl+B).
- 4-way **Arrow navigation pad** (←, ↑, ↓, →) for precise cursor movement.
- Built-in **Advanced Clipboard Manager** with pinned snippets.
- Integrated **Emoji & Kaomoji Hub**.
- **Gemini AI Writer** that drafts text directly into whatever app you are using!

## 🚀 How to Build the APK (2 Methods)

### Method A: Build Free via GitHub Actions (No Android Studio Needed!)
1. Create a new repository on GitHub (e.g. keycraft-keyboard).
2. Upload this folder contents.
3. The included workflow (.github/workflows/build-apk.yml) will automatically run.
4. Go to the Actions tab on GitHub -> click the latest run -> download KeyCraft-Pro-Keyboard.apk from Artifacts!
5. Install on your Android phone.

### Method B: Build with Android Studio
1. Open Android Studio.
2. Select Open and choose this folder.
3. Wait for Gradle sync to complete.
4. Click Build > Build Bundle(s) / APK(s) > Build APK(s).
5. The output APK will be in app/build/outputs/apk/debug/app-debug.apk.

## 📱 How to Set as Default Keyboard on Android
1. Install KeyCraft-Pro-Keyboard.apk on your Android phone.
2. Tap the KeyCraft Pro app icon from your home screen or App Drawer.
3. Tap "Step 1: Enable in System Settings" -> turn on KeyCraft Pro Keyboard.
4. Tap "Step 2: Select Input Method" -> choose KeyCraft Pro Keyboard.
5. Done! Now open WhatsApp, Chrome, or any text field and KeyCraft Pro will appear as your default keyboard!
